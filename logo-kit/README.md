# Mechbridge logo kit

Every logo comes as an SVG (`svg/`, scalable, for print and the web) and a transparent PNG (`png/`, 2000 px on the long side). Open `index.html` to see them all on the backgrounds they are made for, or `contact-sheet.jpg` for one image of everything.

Rebuild with `npm run logos` (source: `scripts/make-logos.mjs`, artwork: `src/data/logo-inner.svg`). Don't edit the files by hand.

## Lockups

| Folder | What it says | Use it for |
|---|---|---|
| `stacked-full` | Monogram over MECHBRIDGE INTERNATIONAL MEP CONSULTANTS | Letterheads, certificates, proposals, signage |
| `horizontal-full` | Monogram beside MECHBRIDGE INTERNATIONAL MEP CONSULTANTS | Email signatures, website headers, banners, document footers |
| `stacked-name` | Monogram over MECHBRIDGE INTERNATIONAL | Social posts, presentations |
| `horizontal-name` | Monogram beside MECHBRIDGE INTERNATIONAL | Narrow headers, slides |
| `stacked` | Monogram over MECHBRIDGE (the current logo) | Small spaces where the full name won't read |
| `horizontal` | Monogram beside MECHBRIDGE | Very short bars and tabs |
| `wordmark-full`, `wordmark-name`, `wordmark` | Lettering only | Where the monogram already appears nearby |
| `mark` | Monogram only | Profile pictures, app icons, favicons, stamps |

## Colours

| Name | Colours | Background |
|---|---|---|
| `navy` | Midnight Navy #1A2841 | Cream, white and light photos |
| `cream` | Old Cream #F0E1CE | Navy and dark backgrounds |
| `white` | #FFFFFF | Dark photos and dark backgrounds |
| `black` | #000000 | One-colour print, stamps, fax |
| `red` | Vintage Red #B11722 | Cream and white |
| `duo` | Red monogram and rules, navy lettering | Cream and white |

Never put the red or duo versions on navy (red on navy fails contrast; use cream or white there).

## Type

MECHBRIDGE is the original drawn wordmark. INTERNATIONAL is set in Geist SemiBold and MEP CONSULTANTS in Geist Mono Medium, the website's typefaces, converted to outlines so the files need no fonts installed.

## Space and size

Keep clear space around the logo at least the height of the "M" crossbar. Don't stretch, recolour outside this palette, add shadows or outlines, or rearrange the parts. Smallest sizes: full lockups 40 mm / 240 px wide, name lockups 30 mm / 180 px, monogram 8 mm / 32 px.
